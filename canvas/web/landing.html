How it works

Six steps, no surprises. Each one has a concrete output you can review.

  1. Arranca el servidor local (dart run bin/servidor.dart) y abre el canvas web.
  2. Selecciona tu proyecto y archivo desde el explorador inteligente (escaneo AST automático).
  3. Carga la captura de tu app real en el marco del emulador con opacidad regulable.
  4. Anota con herramientas visuales (Callouts numerados, flechas, cajas de rediseño, reglas) o añade widgets Material 3.
  5. Personaliza en el Inspector lateral: textos, colores, bordes, iconos y comportamiento.
  6. Exporta el prompt quirúrgico o genera el código directamente con el motor de IA integrado (Groq).
  1. Start the local server (dart run bin/servidor.dart) and open the web canvas.
  2. Select your project and file from the smart explorer (automatic AST scanning).
  3. Load a real app screenshot inside the emulator frame with adjustable opacity.
  4. Annotate with visual tools (numbered Callouts, arrows, redesign boxes, rulers) or add Material 3 widgets.
  5. Customize in the Side Inspector: texts, colors, borders, icons, and behavior notes.
  6. Export the surgical prompt or generate code directly with the integrated AI engine (Groq).

Preguntas rápidasQuick questions

¿Qué es el modo de edición sobre captura real?What is real screenshot editing mode?

Te permite usar una captura de tu aplicación real en ejecución como fondo dentro del marco del emulador (Móvil V, H o Web), con opacidad ajustable. Así puedes diseñar y anotar cambios visuales directamente sobre la vista real sin lidiar con BLoCs, GetIt o audio nativo que no compilarían en un navegador aislado.It lets you place a real screenshot of your running app as the background of the emulator frame (Mobile V, H, or Web) with adjustable opacity. You can design and annotate visual changes directly over the real UI without dealing with BLoCs, GetIt, or native audio that cannot compile in an isolated browser.

¿Sube mi código a algún servidor externo?Does it upload my code to any external server?

No. Todo el análisis AST, el servidor local y el canvas corren en tu propia máquina en 127.0.0.1. Si usas el motor de IA, este solo consulta la API del proveedor que tú elijas (como Groq u OpenAI) con tu propia clave.No. All AST analysis, the local server, and the canvas run on your own machine at 127.0.0.1. If you use the AI engine, it only queries your chosen provider API (such as Groq or OpenAI) using your own key.

¿Reemplaza a Flutter DevTools?Does it replace Flutter DevTools?

No, son complementarios. DevTools inspecciona y perfila una app en ejecución; ApliArte Widget Canvas bocetea y documenta cambios visuales quirúrgicos antes de tocar código.No, they're complementary. DevTools inspects and profiles a running app; ApliArte Widget Canvas sketches and documents surgical visual changes before writing code.

¿Funciona con cualquier proyecto Flutter?Does it work with any Flutter project?

Con cualquiera que tenga estructura estándar lib/ y pubspec.yaml. Probado contra CalcaApp (7M+ descargas) y proyectos avanzados con Clean Architecture.With any project having a standard lib/ and pubspec.yaml structure. Tested against CalcaApp (7M+ downloads) and advanced Clean Architecture projects.

It's a tool for keeping several Flutter versions installed without them clashing between projects.

Ahora sí, a probarloNow, try it

# Clona el repo / Clone the repo
git clone https://github.com/erbolamm/apliarte-widget-canvas.git

# Terminal 1 — servidor local / local server
cd apliarte-widget-canvas/servidor
dart run bin/servidor.dart

# Terminal 2 (nueva / new) — canvas
cd apliarte-widget-canvas/canvas
fvm flutter run -d chrome

⚠️ Cada bloque asume una terminal nueva desde la raíz del repo. "Address already in use" en el servidor: ya tienes uno corriendo de antes — lsof -i :8799 + kill, o simplemente úsalo.Each block assumes a new terminal from the repo root. "Address already in use" on the server means one is already running — lsof -i :8799 + kill, or just use it.

Con las dos terminales corriendo, ya no necesitas escribir rutas a mano: el canvas incluye un Explorador Inteligente que escanea automáticamente todas las pantallas y widgets de tu proyecto. Eliges tu pantalla con un clic, o cargas una captura de tu app real en el emulador para empezar a diseñar y anotar inmediatamente.With both terminals running, you don't even need to type paths by hand: the canvas includes a Smart Project Explorer that automatically scans all screens and widgets in your project. Pick your screen in one click, or load a screenshot of your real app into the emulator frame to start designing and annotating immediately.
